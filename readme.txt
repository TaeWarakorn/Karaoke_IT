KaraokeIT
============

วางลิงก์ YouTube แล้วแอปจะตัดเสียงร้องออก เหลือดนตรีพร้อมวิดีโอและซับเนื้อเพลง

วิธีใช้
1. ดับเบิลคลิกไอคอน "KaraokeIT" บนหน้าจอ Desktop
2. หน้าต่างแอปจะเปิดขึ้นมาเอง วางลิงก์ YouTube แล้วกด "สร้างKaraokeIT"
3. เลิกใช้ให้กดปุ่ม "ปิดโปรแกรม" มุมขวาบนของแอป

สิ่งที่ควรรู้
- เครื่องที่มีการ์ดจอ NVIDIA ใช้ราวหนึ่งนาทีต่อเพลง เครื่องที่ไม่มีใช้ราว 3-5 นาทีต่อเพลง
- เพลงแรกจะช้ากว่าปกติ เพราะต้องดาวน์โหลดโมเดล AI (ราว 3 GB สำหรับระบบซับวิ่ง)
- เพลงที่ทำแล้วเก็บอยู่ในโฟลเดอร์ library เปิดซ้ำได้ทันที
- ถ้าดาวน์โหลดเพลงไม่ได้ ให้กดปุ่ม "ตรวจหาอัปเดต" มุมขวาบนของแอป แล้วกด "อัปเดตเลย"
- ถอนการติดตั้งได้จาก Start Menu > KaraokeIT > ถอนการติดตั้ง
- ใช้ร้องเล่นส่วนตัวเท่านั้น เพลงส่วนใหญ่มีลิขสิทธิ์ ห้ามนำไฟล์ไปเผยแพร่ต่อ
